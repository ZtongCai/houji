# 后稷 (Project Houji) 项目总纲

## 1. 核心愿景

构建一个名为"后稷"的物理世界 AI 智能体。它在一个 50×50×100cm 的密闭帐篷内，通过阿里云百炼 qwen3.7-plus 辅助决策，并由 Streamlit 呈现包含“AI 思考过程”的实时看板。

## 2. 硬件拓扑

"脑-脊髓"分布式控制架构：

- **大脑 (Pi 5)**：Python 主控、图像处理、AI 调度、数据存储
- **脊髓 (Pico)**：USB 串口接收 JSON 指令，驱动 8 路继电器控制物理设备
- **摄像头 (USB)**：OpenCV 采图，每 30 分钟定时快照，硬件倒置已做 180° 翻转修正
- **环境传感 (7合1)**：温度/湿度/CO₂/TVOC/CH₂O/PM2.5/PM10，每 10 秒采集，串口 `/dev/ttyAMA0`
- **水质传感 (TDS/EC)**：营养液 EC 浓度（μS/cm），ADS1115 ADC → I2C 0x48，含温度补偿

## 3. AI 与数据栈

| 模块 | 技术 | 状态 |
|---|---|---|
| 决策引擎 | 顺序决策管线 + 阿里云百炼 qwen3.7-plus 单模型直连 | ✅ 已实装 |
| 短期记忆 | SQLite (`houji.db`) + 10队列趋势池 | ✅ 已实装 |
| 长期记忆 | 按实际需求再选方案 | 尚未实现 |

## 4. 看板与直播架构

采用"局域网生产-消费解耦"模式：

- **数据存储**：Pi 5 上的 SQLite、AI 日志与摄像头快照
- **渲染看板**：Pi 5 上的 Streamlit（`dashboard/Streamlit/app.py`）
- **公网访问**：cpolar China 隧道随 `houji.target` 启动

## 5. 工程原则

- **物理隔离**：12V 和 220V 设备通过继电器 4/5/6 硬件隔离带分区
- **安全优先**：
  - 蠕动泵（relay 1）：强制 `duration_seconds` 定时保护，代码层硬性截断 ≤10s
  - 进排气扇（relay 2/3）：必须联动开关，固定 120s 通风，禁止持续开（duration=0）
  - 打氧泵（relay 7）：夜间静音禁止常规开启，代码层硬性截断 ≤300s
- **扁平结构**：不过度抽象，优先可读性
- **存活优先**：AI 即使返回空动作，系统也不崩溃
