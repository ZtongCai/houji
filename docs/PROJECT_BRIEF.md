# 后稷 (Project Houji) 项目总纲

## 1. 核心愿景

构建一个名为"后稷"的物理世界 AI 智能体（Agent）。它将在一个 50x50x100cm 的密闭帐篷内，通过大模型自主决策，全程接管两棵水培生菜的生命周期，并最终在 Windows 端呈现包含"AI 思考过程"的极客风直播看板（致敬 Sol 模式）。

## 2. 硬件拓扑

这是一个典型的"脑-脊髓"分布式控制架构：

- **大脑中枢 (Pi 5)**：树莓派 5 负责跑 Python 主控、图像处理、AI 调度和数据分发。
- **脊髓执行 (Pico)**：树莓派 Pico 通过 USB 串口与 Pi 5 通讯，底层驱动工业级继电器板，控制物理设备（全光谱补光灯、排气扇、蠕动泵）。
- **视觉感知 (Camera)**：树莓派 Camera V1.3，固定机位，提供定时高清快照。

## 3. AI 与数据栈

- **决策引擎**：Gemini Flash（日常）/ Gemini Pro（疑难）
- **长期记忆**：LightRAG（NanoVectorDB + NetworkX）
- **短波记忆**：SQLite

## 4. 直播与展现架构

采用"局域网生产-消费解耦"模式：

- **数据网关**：Pi 5 开启 Samba，将 `brain/data/` 映射给 Windows（Z: 盘）
- **渲染看板**：Windows 端 Streamlit 定时读取共享盘
- **直播推流**：OBS Studio 截屏 Streamlit 窗口

## 5. 工程原则

- 物理隔离：逻辑代码与继电器代码严格分离
- 扁平起步：MVP 结构，按需重构
- 存活优先：Phase 1 只关注硬件跑通和基础生存控制
